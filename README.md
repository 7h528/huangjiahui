# 珠海科技学院校园活动聚合站（Campus Activity Hub）

一个简洁的校园活动信息聚合网页，帮助学生快速发现和筛选校内各类活动。

## 主要解决的问题

校园里的竞赛、讲座、招募、学习小组等活动信息分散在各个群聊、公众号和通知文件中，学生容易错过截止时间，也难以快速筛选出适合自己的活动。本站把这些信息集中到一个网页上，支持浏览、筛选、搜索和自主发布，让学生不再到处翻群。

## 项目结构

```
├── index.html   # 页面结构
├── style.css    # 样式（含学校主题色、响应式）
├── script.js    # 交互逻辑与26条内置活动数据
└── README.md    # 项目说明
```

## 核心功能

- **活动浏览**：卡片式展示全部 26 条模拟校园活动信息
- **多维筛选**：按活动类型、发布方（官方/学生自发）、活动状态筛选
- **关键词搜索**：按活动标题或简介实时搜索
- **倒计时提示**：自动计算报名截止剩余时间，按紧急程度用不同颜色提示；过期活动自动置灰并排序靠后
- **活动发布**：通过表单提交新活动，数据保存在 localStorage，刷新不丢失

## 自主设计的创新功能

**智能倒计时 + 状态自动标记系统**
- 每条活动自动计算距离报名截止的剩余时间，按紧急程度用不同颜色区分（绿色充裕 / 黄色临近 / 红色紧急 / 灰色已截止）
- 已截止或已结束的活动自动置灰，排在列表后面，避免学生误点
- 对"长期招募""截止时间未注明"的活动单独标注状态标签

## 主动发现并处理的关键问题

题目材料中 26 条信息质量参差不齐：有的信息完整，有的缺失截止时间、地点，还有的（如第 24 条"校园兼职福利分享"、第 25 条"数码新品体验交流"）信息不完整甚至带有商业推广性质、要求加私人微信，存在安全隐患。

**处理方式：**
- 对信息不完整的条目，保留原文并在卡片上用警示条标注具体缺失内容，不擅自编造
- 对信息存疑、疑似营销或存在安全风险的条目，用醒目警示条明确提示"信息存疑，请谨慎辨别，谨防诈骗"
- 将官方发布与学生自发信息用不同颜色标签区分（蓝色"官方" vs 橙色"学生发起"）

## 运行方式

将项目文件放在同一文件夹，直接用浏览器打开 index.html 即可运行，无需后端服务器。
